# Odin Recipes

## About

This is a recipe website built to complete a project from The Odin Project curriculum. It has four pages: a home page with links to three recipes (lasagna, tacos al pastor and Spanish tortilla), and each recipe page has a link back to the home page.

## Skills practiced

- Building the basic structure of an HTML page (`<!DOCTYPE>`, `<head>`, `<body>`).
- Using headings to organize content: `<h1>` for the page title and `<h2>` for each section.
- Choosing the right list: unordered lists (`<ul>`) for ingredients and ordered lists (`<ol>`) for steps, because the order of the steps matters.
- Adding images with `src` and descriptive `alt` text.
- Linking pages with relative paths (`./` for the current folder and `../` to go up one folder).
- Using Git from the terminal: `git status`, `git add`, `git commit` and `git push`, and making atomic commits with clear messages.

## Reflection

I learned new VS Code shortcuts that made my work faster: Emmet's "Wrap with Abbreviation", toggling comments and find-and-replace. I also learned to always check `git status` before committing, so each commit only includes what I mean to save.
